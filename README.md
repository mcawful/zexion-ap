# zexion-ap

[Archipelago](https://archipelago.gg) multiworld support for
[Zexion](https://store.steampowered.com/app/3392510/) (Gallant Leaf, 2025).

**Not usable yet.** The project is in its go/no-go phase: working out from the game's saves and
memory whether items can be placed, sent and received at all. There is no APWorld and no client.
What has been learned so far is recorded, with its evidence, in [`docs/re/`](docs/re/README.md).

This is an unofficial fan project, not affiliated with Gallant Leaf. It contains no game files;
you need your own copy of Zexion.
