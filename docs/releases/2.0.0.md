## What's new

- **Zexion on Linux and the Steam Deck.** A new mod, `libzexion_ap.so`, loads through a Steam launch option and does what the Windows mod does: new games from the menu, item popups, traps, DeathLink, the OS Install Disks goal, translations, and no Feats or achievements in Archipelago saves. It has been tried on one Linux PC and loaded on a Steam Deck, and it is not yet fully played in game there. Restart Zexion instead of using the client's `/reload_mod`. It is for Zexion's Linux version only, not the Windows one under Proton. See "Linux and Steam Deck" in the setup guide.
- **Your Archipelago saves follow you to another machine with Steam Cloud.** The mod keeps a small `ZexionAP-seed-*.sav` copy beside your saves, so a machine that gets them from Steam can tell them from plain randomizer saves. Both machines need the mod, and Steam must have synced before you start Zexion on the second. It has worked between two Windows PCs, and once from Windows to a Linux PC. It is not yet tried from a Steam Deck to another machine, or from Linux to Windows.
- **The mod finds what it needs in the game itself,** so the title screen's ARCHIPELAGO lines should show on a first start, with no client connected yet.
- **One download for each system.** The release now has a Windows `.zip` and a Linux `.tar.gz`, each with the mod, the player guides, the sample YAMLs and a short `README.md`. `zexion.apworld` is still there on its own.
- **Energy Shield is filler now,** so the generator can place it where it places filler. With the OS Install Disks goal on accessibility full, a multiworld that has a player on `accessibility: minimal` can still stop with an error, more often with many disks. The goal's option text says how often it did in tests.

## Fixes

- After the server connection drops, loading another save no longer leaves it with INTEL CHIP Area Maps that reveal nothing, a locked ASSIST menu or your seed's disk count.
- On the file select, an Archipelago save's DISK count now follows the entry shown, not a different record of the same save.
- A deleted Archipelago save's logo and DISK count no longer show on a slot where you start a new game.

## Known issue

- On Linux, loading a save state (the game's assist) taken in a different Archipelago save may make the file select's ITEMS row list the wrong starting items, and possibly send that other save's checks or give its items too; this is not yet checked on Linux. Windows is not affected.

## Updating from 1.2.0

- Replace `zexion.apworld`, `zexion_ap.dll` and `version.dll` together, from the Windows archive. A 1.2.0 `zexion_ap.dll` left in the folder makes the client say the mod and the client don't match.
- With Steam Cloud on, the mod now keeps `ZexionAP-seed-*.sav` files in your save folder. Leave them alone, and update the mod on your other machines too.
- On Linux or the Steam Deck this is a new install: follow "Linux and Steam Deck" in the setup guide.
